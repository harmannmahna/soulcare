# Fine-tune Qwen2.5-0.5B (LoRA) for SoulCare risk labels

Hackathon path: a few hundred labelled rows, 3 epochs, LoRA r=8. Runtime still ships a sklearn TF-IDF + logistic regression artifact so the API works on Render **without a GPU**. After you train, drop the adapter in and set `RISK_MODEL_PATH`.

**Keyword OR-red stays on.** If either the model **or** the phrase rail flags red, the turn is red. The model cannot downgrade a crisis phrase.

## Do you need an API key?

| Thing | Required? |
| --- | --- |
| OpenAI / Gemini / paid GPU API | **No** |
| Hugging Face account | Only if the Qwen download is gated |
| `HF_TOKEN` | Optional. Create a free read token at huggingface.co → Settings → Access Tokens if `from_pretrained` asks to log in |
| Qwen licence click | Once, free, in the browser: [Qwen/Qwen2.5-0.5B](https://huggingface.co/Qwen/Qwen2.5-0.5B) → accept |
| Colab | Free GPU (T4) is enough |

If Qwen is too heavy for the machine, use DistilBERT LoRA instead (same labels, same export folder). DistilBERT is public — **no token**.

## Dataset

`backend/ml/data/risk_dataset.csv` (English + Hinglish, labels `green` / `yellow` / `red`). Regenerated by `backend/ml/dataset.py`.
