# Glowinn — Made for Modern Elegance

Standalone React + Vite (JSX) beauty landing: floating pill navbar, full-viewport looping forest-floor hero, mossy glass foot cards.

```bash
cd glowinn
npm install
npm run dev
```

Hero video is committed at `public/hero.mp4` and served as `/hero.mp4`. Do not hotlink an external URL.

## Deploy (Vercel)

Set the project **Root Directory** to `glowinn`. This folder’s `vercel.json` builds the site and rewrites SPA paths to `index.html`.
